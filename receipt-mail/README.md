# ระบบบันทึกการส่งใบเสร็จ

โปรแกรมบันทึกงานส่งจดหมายใบเสร็จให้ลูกค้า ใช้งานผ่านเบราว์เซอร์ได้หลายเครื่องในวง LAN หรือขึ้น Vercel

## สิ่งที่บันทึก

ระบบบันทึกเป็น **ซอง** โดย 1 ซองคือพัสดุ 1 ชิ้นที่ส่งให้ลูกค้า ในซองเดียวมีใบเสร็จได้หลายใบ

**ใบเสร็จในซอง** (มีได้หลายใบ)

| ช่อง | หมายเหตุ |
|---|---|
| เลขที่ใบเสร็จ | ต้องกรอก ถ้าเลขนี้เคยอยู่ในซองอื่นแล้ว ระบบจะขึ้นคำเตือน |
| วันที่ตัดบิล | ต้องกรอก แถวใหม่จะใช้วันที่เดียวกับแถวก่อนหน้าให้อัตโนมัติ |

**ข้อมูลการส่ง** (กรอกครั้งเดียวต่อซอง)

| ช่อง | หมายเหตุ |
|---|---|
| ชื่อลูกค้า | ต้องกรอก ถ้าเคยส่งให้ลูกค้ารายนี้แล้ว ระบบจะเติมที่อยู่และวิธีส่งของครั้งล่าสุดให้ |
| วันที่ส่ง | เว้นว่างได้ ถ้าว่างจะถือว่ายังไม่ส่ง (สถานะ "รอส่ง") |
| ส่งไปที่ | ชื่อผู้รับและที่อยู่ |
| ส่งทาง | เช่น ไปรษณีย์ไทย (EMS), Kerry, Flash หรือส่งเอง |
| เลขพัสดุ | ใช้ตรวจสอบ ถ้าส่งทางไปรษณีย์ไทย กดที่เลขจะเปิดหน้าติดตามพัสดุ ถ้าเป็นขนส่งอื่น มีปุ่มคัดลอกเลข |
| สถานะ | รอส่ง, ส่งแล้ว, ลูกค้าได้รับแล้ว หรือตีกลับ |

## ความสามารถ

- ใส่ใบเสร็จในซองได้เร็ว: กด Enter เพื่อเพิ่มแถวถัดไป หรือคัดลอกเลขหลายใบจาก Excel มาวางทีเดียว ระบบจะแยกเป็นแถวให้
- ค้นหาจากเลขใบเสร็จได้ ระบบจะแสดงซองที่มีใบเสร็จนั้นอยู่ ค้นจากชื่อลูกค้า เลขพัสดุ หรือที่อยู่ก็ได้ กรองตามช่วงวันที่ตัดบิลหรือวันที่ส่ง และตามสถานะได้
- สรุปจำนวนซองและจำนวนใบเสร็จแยกตามสถานะ
- พิมพ์ใบแนบซองที่แสดงรายการใบเสร็จในซองได้ ใช้ใส่ไปกับซองหรือเก็บเป็นหลักฐาน
- เก็บประวัติการแก้ไขทุกครั้ง รวมถึงการเพิ่มหรือเอาใบเสร็จออกจากซอง ลบซองได้เฉพาะผู้ดูแลและต้องระบุเหตุผล ซองที่ลบจะถูกซ่อนไว้ ไม่ได้หายจริง
- พิมพ์รายการซอง และส่งออก Excel ได้ ไฟล์ Excel จะเป็น 1 แถวต่อใบเสร็จ พร้อมข้อมูลซองที่ใบเสร็จนั้นอยู่
- **นำเข้าจาก Excel** (.xlsx, .xls หรือ .csv) ที่หน้ารายการ ระบบจะตรวจไฟล์และแสดงตัวอย่างพร้อมแถวที่มีปัญหาก่อนให้กดยืนยัน
  - ในไฟล์ 1 แถวคือใบเสร็จ 1 ใบ ใบเสร็จที่มีเลขพัสดุเดียวกันจะรวมเป็นซองเดียว ถ้ายังไม่มีเลขพัสดุ จะรวมใบที่ลูกค้า วันที่ส่ง และที่อยู่ตรงกันเป็นซองเดียว
  - ระบบอ่านหัวคอลัมน์ภาษาไทยได้เอง ลำดับคอลัมน์ไม่สำคัญ และมีไฟล์แม่แบบให้ดาวน์โหลด
  - วันที่ใช้ได้ทั้ง วว/ดด/ปปปป (พ.ศ. หรือ ค.ศ.) และวันที่แบบ Excel
  - ถ้าใบเสร็จมีอยู่ในระบบแล้ว เลือกได้ว่าจะ "ข้าม" หรือ "อัปเดตซองเดิม" แบบอัปเดตใช้เติมวันที่ส่งหรือเลขพัสดุภายหลังได้ ไฟล์มีแค่คอลัมน์เลขที่ใบเสร็จ วันที่ส่ง และเลขพัสดุก็พอ
  - ระบบบันทึกทั้งไฟล์ในครั้งเดียว ถ้าบันทึกไม่สำเร็จจะไม่มีข้อมูลจากไฟล์เข้าระบบเลย ส่วนแถวที่มีปัญหาจะถูกข้ามไป
- ผู้ใช้มี 2 สิทธิ์ คือผู้ดูแลและพนักงาน

## ติดตั้งและเปิดใช้งาน (ในออฟฟิศ)

ต้องมี [Node.js](https://nodejs.org/) รุ่น 22 ขึ้นไป

```bash
cd receipt-mail
npm install
```

เปิดโปรแกรม: ดับเบิลคลิก `start.bat` (หรือรัน `node server.js`) แล้วเปิด http://localhost:3001
เครื่องอื่นในวงเดียวกันเข้าผ่าน `http://<IP เครื่องนี้>:3001`

เปิดครั้งแรก ระบบจะให้สร้างบัญชีผู้ดูแล ข้อมูลเก็บที่ `receipt-mail/data/receipts.db` ควรสำรองไฟล์นี้เป็นระยะ

ใช้พอร์ต 3001 จึงเปิดพร้อมกับระบบสต็อกหนังสือ (พอร์ต 3000) บนเครื่องเดียวกันได้ ถ้าต้องการเปลี่ยนพอร์ต ให้ตั้งตัวแปร `PORT`

## ขึ้นออนไลน์บน Vercel (ถ้าต้องการ)

1. สร้างฐานข้อมูลใหม่บน [Turso](https://turso.tech) ให้แยกจากของระบบสต็อก
2. ใน Vercel ให้สร้าง Project ใหม่จาก repo นี้ แล้วตั้ง **Root Directory = `receipt-mail`**
3. ตั้งค่า Environment Variables คือ `TURSO_DATABASE_URL` และ `TURSO_AUTH_TOKEN` แล้ว Deploy
