# ระบบบันทึกการส่งใบเสร็จ

โปรแกรมบันทึกงานส่งจดหมายใบเสร็จให้ลูกค้า ใช้งานผ่านเบราว์เซอร์ได้หลายเครื่องในวง LAN หรือขึ้น Vercel

## สิ่งที่บันทึก

ระบบบันทึกเป็น **ซอง** โดย 1 ซองคือพัสดุ 1 ชิ้นที่ส่งให้ลูกค้า ในซองเดียวมีใบเสร็จได้หลายใบ

**ใบเสร็จในซอง** (มีได้หลายใบ)

| ช่อง | หมายเหตุ |
|---|---|
| เลขที่ใบเสร็จ | ต้องกรอก ถ้าเลขนี้เคยอยู่ในซองอื่นแล้ว ระบบจะขึ้นคำเตือน |
| ชื่อลูกค้า | ถ้าเว้นว่าง จะใช้ชื่อผู้รับซอง ใส่เมื่อใบเสร็จเป็นของลูกค้ารายอื่น เช่น ส่งใบเสร็จของสาขารวมไปที่สำนักงานใหญ่ |
| รายละเอียดสินค้า | เช่น หนังสือเรียน ป.1 x 50 เล่ม |
| ยอดเงิน (บาท) | ไม่บังคับ ระบบจะรวมยอดให้ทั้งซอง เก็บเป็นสตางค์ ยอดรวมจึงไม่เพี้ยนจากทศนิยม |

**ข้อมูลการส่ง** (กรอกครั้งเดียวต่อซอง)

| ช่อง | หมายเหตุ |
|---|---|
| ชื่อลูกค้า | ต้องกรอก ถ้าเคยส่งให้ลูกค้ารายนี้แล้ว ระบบจะเติมที่อยู่และวิธีส่งของครั้งล่าสุดให้ |
| วันที่ส่ง | เว้นว่างได้ ถ้าว่างจะถือว่ายังไม่ส่ง (สถานะ "รอส่ง") |
| ส่งไปที่ | ชื่อผู้รับและที่อยู่ |
| ส่งทาง | เช่น ไปรษณีย์ไทย (EMS), Kerry, Flash หรือส่งเอง |
| เลขพัสดุ | ใช้ตรวจสอบ ถ้าส่งทางไปรษณีย์ไทย กดที่เลขจะเปิดหน้าติดตามพัสดุ ถ้าเป็นขนส่งอื่น มีปุ่มคัดลอกเลข |
| สถานะ | รอส่ง, ส่งแล้ว, ลูกค้าได้รับแล้ว หรือตีกลับ |

## ความสามารถ

- **สรุปรายเดือน:** ตารางสรุปแต่ละเดือนตามวันที่ส่ง บอกจำนวนซอง จำนวนใบเสร็จ และจำนวนซองแยกตามสถานะ (ส่งแล้ว / ลูกค้าได้รับแล้ว / ตีกลับ) มีแถวรวมท้ายตาราง
  - เลือกปีและบริษัทผู้ส่งได้ ซองที่ยังไม่ส่งแสดงแยกไว้บรรทัดบนสุด
  - กดที่เดือนเพื่อดูรายการซองของเดือนนั้น และพิมพ์สรุปได้

- **ส่งในนามหลายบริษัท:** ผู้ดูแลเพิ่มบริษัทผู้ส่งพร้อมที่อยู่และเบอร์โทรได้ที่ "ผู้ใช้และตั้งค่า"
  - ตอนบันทึกซองต้องเลือก "ส่งในนามบริษัท" ระบบจำบริษัทที่เลือกล่าสุดไว้ให้
  - หน้าซองและใบรายการ A4 พิมพ์ชื่อ ที่อยู่ และเบอร์โทรของบริษัทที่เลือก
  - แต่ละบริษัทใส่ **ใบอนุญาตชำระค่าฝากส่งเป็นรายเดือน** ของตัวเองได้ ได้แก่ เลขใบอนุญาต (เช่น พิเศษ 3/2559) และที่ทำการไปรษณีย์ (เช่น ปณภ. วารินชำราบ 34190)
    - ระบบพิมพ์เป็นกรอบที่มุมขวาบนของหน้าซอง ถ้าเว้นเลขใบอนุญาตว่าง จะไม่พิมพ์กรอบ
  - หน้ารายการกรองตามบริษัทได้ และแต่ละซองแสดงชื่อบริษัท ไฟล์ Excel ที่ส่งออกมีคอลัมน์ "บริษัทผู้ส่ง"
  - ตอนนำเข้า Excel เลือกบริษัทเริ่มต้นได้ หรือใส่คอลัมน์ "บริษัทผู้ส่ง" ในไฟล์ก็ได้
  - ถ้าเลิกใช้บริษัทใด ให้ปิดใช้งานแทนการลบ ซองเก่าจะยังแสดงชื่อบริษัทเดิมได้
  - ตอนอัปเดตเป็นเวอร์ชันนี้ ระบบสร้างบริษัทแรกจากชื่อและที่อยู่ผู้ส่งที่ตั้งไว้เดิม และให้ซองเดิมทั้งหมดเป็นของบริษัทนั้น

- **ช่องวันที่ใช้รูปแบบ วว/ดด/ปปปป (พ.ศ.)** เช่น 05/11/2569 พิมพ์ได้หลายแบบ เช่น 05112569, 5/11/69 หรือปี ค.ศ. 5/11/2026 ระบบจะแปลงให้เอง หรือกดปุ่ม 📅 เพื่อเลือกจากปฏิทิน

- **สมุดที่อยู่ลูกค้า** (เมนู "สมุดที่อยู่ลูกค้า") เก็บชื่อ ที่อยู่ เบอร์โทร และหมายเหตุของลูกค้า เพิ่ม แก้ ค้นหา และนำเข้าจาก Excel ได้
  - ตอนบันทึกซอง พิมพ์หรือเลือกชื่อลูกค้า ระบบจะเติมที่อยู่ให้ ไม่ต้องคีย์ซ้ำ
  - ลูกค้าใหม่จะถูกเพิ่มลงสมุดให้อัตโนมัติตอนบันทึกซอง
  - ถ้าพิมพ์ที่อยู่ต่างจากในสมุด ระบบจะเตือน ติ๊ก "อัปเดตที่อยู่นี้ลงสมุดลูกค้าด้วย" เพื่อเปลี่ยนที่อยู่ในสมุด หรือกด "ใช้ที่อยู่ในสมุด" เพื่อกลับไปใช้ที่อยู่เดิม
  - แก้ที่อยู่ในสมุดแล้ว ซองที่บันทึกไปก่อนหน้าจะยังเก็บที่อยู่ตอนส่งไว้เหมือนเดิม
  - ตอนอัปเดตเป็นเวอร์ชันนี้ครั้งแรก ระบบจะสร้างสมุดจากที่อยู่ล่าสุดที่เคยส่งให้ลูกค้าแต่ละรายให้

- ใส่ใบเสร็จในซองได้เร็ว: กด Enter เพื่อเพิ่มแถวถัดไป หรือคัดลอกเลขหลายใบจาก Excel มาวางทีเดียว ระบบจะแยกเป็นแถวให้
- ค้นหาจากเลขใบเสร็จได้ ระบบจะแสดงซองที่มีใบเสร็จนั้นอยู่ ค้นจากชื่อลูกค้า เลขพัสดุ หรือที่อยู่ก็ได้ กรองตามช่วงวันที่ส่ง บริษัทผู้ส่ง และสถานะได้
- สรุปจำนวนซองและจำนวนใบเสร็จแยกตามสถานะ
- **พิมพ์ได้ทันทีหลังบันทึก:** หลังกดบันทึกซอง จะมีปุ่ม "พิมพ์หน้าซอง" และ "พิมพ์ใบรายการใบเสร็จ" ของซองนั้นอยู่ด้านบนหน้า ถ้าบันทึกหลายซองต่อกัน กดพิมพ์ของทุกซองในรอบนั้นพร้อมกันได้
- **พิมพ์หน้าซอง:** พิมพ์ทีละซองหรือหลายซองพร้อมกันก็ได้ ติ๊กเลือกซองในหน้ารายการ แล้วกด "พิมพ์หน้าซอง" ระบบจะแสดงตัวอย่างให้ดูก่อนพิมพ์
  - เลือกได้ว่าจะพิมพ์ชื่อและที่อยู่ผู้ส่งหรือไม่ เช่น ใช้ซองที่พิมพ์โลโก้และที่อยู่บริษัทไว้แล้ว ระบบจำตัวเลือกไว้ให้ครั้งต่อไป
  - บนซองมีชื่อและที่อยู่ผู้ส่ง ผู้รับพร้อมที่อยู่ ช่องรหัสไปรษณีย์ และเลขที่ใบเสร็จตัวเล็กสำหรับตรวจของในซอง ซึ่งจะปิดไว้ก็ได้
  - ผู้ดูแลตั้งที่อยู่ผู้ส่ง ขนาดซอง และตำแหน่งตัวหนังสือได้ที่เมนู "ผู้ใช้และตั้งค่า" ขนาดเริ่มต้นคือ 9 × 12½ นิ้ว มีขนาดสำเร็จรูปให้เลือก
  - ตอนสั่งพิมพ์ ให้เลือกขนาดกระดาษในเครื่องพิมพ์ให้ตรงกับขนาดซอง และตั้งขอบกระดาษ (Margins) เป็น "ไม่มี"
  - หน้าซองใช้ฟอนต์ **TH Sarabun New** ชื่อและที่อยู่ผู้รับ 18pt ผู้ส่ง 16pt และกรอบใบอนุญาต ปณ. 12pt
    - เครื่องที่สั่งพิมพ์ต้องติดตั้งฟอนต์ TH Sarabun New (ฟอนต์ฟรีของ SIPA เครื่องที่มีชุดฟอนต์ราชการมักมีอยู่แล้ว) ถ้าไม่มี ระบบจะใช้ฟอนต์ Sarabun แทน ซึ่งตัวใหญ่กว่าเล็กน้อย
- **พิมพ์ใบรายการใบเสร็จ** ขนาด A4 สำหรับใส่ไปในซองให้ลูกค้า บอกว่าในซองมีใบเสร็จกี่ฉบับ และแต่ละฉบับคือเลขที่ใด ของลูกค้ารายใด ลงวันที่เท่าไร มีช่องให้ลูกค้าติ๊กตรวจรับ พิมพ์ทีละซองหรือเลือกหลายซองพร้อมกันได้
  - มีรายละเอียดสินค้าและจำนวนเงินของแต่ละใบ (ไม่แสดงยอดรวม)
  - ใช้ฟอนต์ **TH Sarabun New 16pt** ชื่อบริษัท 18pt หัวเรื่อง 20pt ถ้าเครื่องที่พิมพ์ไม่มีฟอนต์นี้ จะใช้ Sarabun แทน
  - เลือกได้ว่าจะแสดงยอดเงิน รายละเอียดสินค้า ช่องลงชื่อผู้จัดส่งและผู้รับ หมายเหตุ และเบอร์ติดต่อกลับหรือไม่
- **การแก้ไขต้องกรอกหมายเหตุ** ว่าแก้อะไรและเพราะอะไร ระบบบันทึกชื่อผู้แก้ไขและเวลาให้อัตโนมัติ
  - ประวัติการแก้ไขแสดงแต่ละช่องที่เปลี่ยนเป็นแบบ ค่าเดิม → ค่าใหม่
  - ถ้าใบเสร็จในซองเปลี่ยน จะแสดงว่าเพิ่มหรือเอาใบไหนออก และแก้ช่องใดของใบไหน เช่น "PR2: ยอดเงิน 1,500.00 → 777.00"
  - ในหน้ารายการ ซองที่เคยแก้จะมีป้าย "✎ แก้ไข N ครั้ง" เอาเมาส์ชี้จะเห็นว่าใครแก้ล่าสุด
  - ถ้าแก้ผ่านการนำเข้า Excel หมายเหตุจะเป็น "นำเข้าจากไฟล์ Excel"
- เก็บประวัติการแก้ไขทุกครั้ง รวมถึงการเพิ่มหรือเอาใบเสร็จออกจากซอง ลบซองได้เฉพาะผู้ดูแลและต้องระบุเหตุผล ซองที่ลบจะถูกซ่อนไว้ ไม่ได้หายจริง
- พิมพ์รายการซอง และส่งออก Excel ได้ ไฟล์ Excel จะเป็น 1 แถวต่อใบเสร็จ พร้อมข้อมูลซองที่ใบเสร็จนั้นอยู่
- **นำเข้าจาก Excel** (.xlsx, .xls หรือ .csv) ที่หน้ารายการ ระบบจะตรวจไฟล์และแสดงตัวอย่างพร้อมแถวที่มีปัญหาก่อนให้กดยืนยัน
  - ในไฟล์ 1 แถวคือใบเสร็จ 1 ใบ ใบเสร็จที่มีเลขพัสดุเดียวกันจะรวมเป็นซองเดียว ถ้ายังไม่มีเลขพัสดุ จะรวมใบที่ลูกค้า วันที่ส่ง และที่อยู่ตรงกันเป็นซองเดียว
  - ระบบอ่านหัวคอลัมน์ภาษาไทยได้เอง ลำดับคอลัมน์ไม่สำคัญ และมีไฟล์แม่แบบให้ดาวน์โหลด อ่านคอลัมน์ "รายละเอียดสินค้า" และ "ยอดเงิน" ได้ด้วย
  - วันที่ใช้ได้ทั้ง วว/ดด/ปปปป (พ.ศ. หรือ ค.ศ.) และวันที่แบบ Excel
  - ถ้าใบเสร็จมีอยู่ในระบบแล้ว เลือกได้ว่าจะ "ข้าม" หรือ "อัปเดตซองเดิม" แบบอัปเดตใช้เติมวันที่ส่งหรือเลขพัสดุภายหลังได้ ไฟล์มีแค่คอลัมน์เลขที่ใบเสร็จ วันที่ส่ง และเลขพัสดุก็พอ
  - ระบบบันทึกทั้งไฟล์ในครั้งเดียว ถ้าบันทึกไม่สำเร็จจะไม่มีข้อมูลจากไฟล์เข้าระบบเลย ส่วนแถวที่มีปัญหาจะถูกข้ามไป
- ผู้ใช้มี 2 สิทธิ์ คือผู้ดูแลและพนักงาน

## ติดตั้งและเปิดใช้งาน (ในออฟฟิศ)

ต้องมี [Node.js](https://nodejs.org/) รุ่น 22 ขึ้นไป

```bash
cd receipt-mail
npm install
```

เปิดโปรแกรม: ดับเบิลคลิก `start.bat` (หรือรัน `node server.js`) แล้วเปิด http://localhost:3001
เครื่องอื่นในวงเดียวกันเข้าผ่าน `http://<IP เครื่องนี้>:3001`

เปิดครั้งแรก ระบบจะให้สร้างบัญชีผู้ดูแล ข้อมูลเก็บที่ `receipt-mail/data/receipts.db` ควรสำรองไฟล์นี้เป็นระยะ

ใช้พอร์ต 3001 จึงเปิดพร้อมกับระบบสต็อกหนังสือ (พอร์ต 3000) บนเครื่องเดียวกันได้ ถ้าต้องการเปลี่ยนพอร์ต ให้ตั้งตัวแปร `PORT`

## ขึ้นออนไลน์บน Vercel (ถ้าต้องการ)

1. สร้างฐานข้อมูลใหม่บน [Turso](https://turso.tech) ให้แยกจากของระบบสต็อก
2. ใน Vercel ให้สร้าง Project ใหม่จาก repo นี้ แล้วตั้ง **Root Directory = `receipt-mail`**
3. ตั้งค่า Environment Variables คือ `TURSO_DATABASE_URL` และ `TURSO_AUTH_TOKEN` แล้ว Deploy
