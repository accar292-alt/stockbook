# ระบบสต็อกหนังสือ

โปรแกรมบันทึกรับเข้า เบิกจ่าย และตัดชำรุดสินค้า (หนังสือ) ใช้งานผ่านเบราว์เซอร์ได้หลายเครื่องในวง LAN

## ความสามารถ

- รับเข้าสินค้า / เบิกจ่ายสินค้า / ตัดชำรุด-เสียหาย พร้อมพิมพ์ใบเอกสาร A4
- สต็อกคงเหลือ แจ้งเตือนเล่มที่ต่ำกว่ายอดขั้นต่ำ (กำหนดรายเล่มได้)
- บัตรสต็อกรายเล่ม ประวัติเอกสาร ยกเลิกเอกสารได้ (ไม่ลบทิ้ง)
- รายงานสรุปยกมา/รับ/เบิก/ชำรุด/คงเหลือ และส่งออก Excel

## ติดตั้งและเปิดใช้งาน

ต้องมี [Node.js](https://nodejs.org/) รุ่น 22.13 ขึ้นไป (ใช้ `node:sqlite` ที่มากับ Node)

```bash
npm install
```

เปิดโปรแกรม: ดับเบิลคลิก `start.bat` (หรือ `node server.js`) แล้วเปิด http://localhost:3000
เครื่องอื่นในวงเดียวกันเข้าผ่าน `http://<IP เครื่องนี้>:3000` (หน้าต่างโปรแกรมจะแสดง IP ให้)

นำเข้ารายชื่อหนังสือจาก `รายการหนังสือทั้งหมด.xlsx` (คอลัมน์: ลำดับ, รหัส, ชื่อเต็มสินค้า):

```bash
node import-books.js
```

## ข้อมูล

- ฐานข้อมูลอยู่ที่ `data/stock.db` (ไม่อยู่ใน git) — สำรองโดยคัดลอกโฟลเดอร์ `data`
- `config.json`: `"requireLogin": false` = ใช้งานได้โดยไม่ต้องเข้าสู่ระบบ, `true` = ต้องเข้าสู่ระบบ (ครั้งแรกจะให้สร้างบัญชีผู้ดูแล)

## ขึ้นเว็บด้วย Vercel

Vercel เก็บไฟล์ถาวรไม่ได้ ฐานข้อมูลบนเว็บจึงอยู่ที่ [Turso](https://turso.tech) (SQLite บนคลาวด์) แยกจากฐานข้อมูลในออฟฟิศ
บนเว็บบังคับเข้าสู่ระบบเสมอ

1. สร้างฐานข้อมูลบน Turso แล้วคัดลอก Database URL (`libsql://...`) และสร้าง Token
2. Vercel → Add New Project → Import repo นี้ → Environment Variables ใส่ `TURSO_DATABASE_URL` และ `TURSO_AUTH_TOKEN` → Deploy
3. (ถ้าต้องการยกข้อมูลจากออฟฟิศขึ้นเว็บ) สร้างไฟล์ `.env` ในโฟลเดอร์นี้ใส่สองค่าเดียวกัน แล้วรัน `node copy-to-turso.js`
   ทำได้ครั้งเดียวตอน Turso ยังว่าง — สคริปต์จะไม่ยอมคัดลอกซ้ำ
